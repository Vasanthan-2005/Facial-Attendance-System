🎯 Facial Recognition-Based Attendance System

🚀 A smart attendance system that eliminates manual attendance marking using facial recognition technology. Ensures accuracy, security, and automation with real-time monitoring and location validation!

---------------------------------------------------------------------------------------------------------------------------------------------------------------

🏆 Key Features

✅ Admin & Student Registration – Both admin and students can register securely

✅ AI-Based Attendance – Mark attendance using facial recognition

✅ Geo-Validation – Students must be within a 50m radius to mark attendance

✅ Admin Dashboard – Monitor attendance, students, and reports

✅ WhatsApp & Email Notifications – Auto-send absentee alerts & attendance reports

✅ Secure Admin Login – CAPTCHA-based authentication for extra security

-------------------------------------------------------------------------------------------------

🛠 Tech Stack

🎯 Backend:

🔹 Flask (Python) – Handles facial recognition & data processing

🔹 Node.js (Express.js) – Manages API routes, attendance operations & notifications

🔹 OpenCV & Face Recognition Library – Face detection & recognition

🔹 FreeSQLDatabase – Stores student & attendance records

🎨 Frontend:

🔹 React (Vite) – Fast, modern, and responsive UI

🔹 Tailwind CSS – Clean and stylish design

-------------------------------------------------------------------------------------------------

🔥 How It Works?

👨‍💻 Admin Registration & Management

1️⃣ Admin signs up with a secure login system.

2️⃣ Admin registers students with their name, ID & facial data.

3️⃣ Admin monitors attendance via a dashboard.

4️⃣ Admin sends alerts & reports via WhatsApp and Email.

🎓 Student Registration & Attendance

1️⃣ Student registers and submits facial data.

2️⃣ To mark attendance, the student scans their face.

3️⃣ System verifies the face & location before logging attendance.

4️⃣ Attendance status is updated in the admin dashboard.
